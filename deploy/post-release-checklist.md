# 发布后巡检清单（Production）

> 适用：单域名 `https://<domain>` 上线后 15 分钟内执行。

## 1) 入口与路由

- [ ] `https://<domain>/` 可打开首页
- [ ] `https://<domain>/admin/login` 可打开后台登录页
- [ ] `https://<domain>/posts`、`/tags` 刷新不 404

## 2) API 与媒体链路

- [ ] `https://<domain>/api/health` 返回 `ok: true`
- [ ] 抽查一张上传图 `https://<domain>/uploads/images/...` 返回 200

## 3) 后台核心操作

- [ ] 管理员登录成功
- [ ] 新建草稿文章并保存成功
- [ ] 发布文章后前台可见
- [ ] 文章下线后前台不可见
- [ ] 精选排序调整后首页顺序生效

## 4) 内容模块回归

- [ ] 友链新增/编辑/删除可用
- [ ] 关于页更新后前台立即可见
- [ ] 名片卡修改后前台立即可见

## 5) 服务与日志

- [ ] 后端进程状态正常（非重启循环）
- [ ] 后端日志无持续报错（500/DB 锁/权限问题）
- [ ] 网站 SSL 正常（HTTP 自动跳 HTTPS）
