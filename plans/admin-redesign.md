# 后台管理页面 Redesign 方案

## 设计方向

**Notion 风格轻量编辑器后台**：简洁侧边栏 + 沉浸式编辑体验，去除冗余装饰，聚焦内容操作。

## 核心设计原则

1. **信息密度优先**：减少卡片嵌套，用留白和边框区分层级
2. **编辑器体验**：文章编辑区采用类 Notion 的大标题 + 可折叠元信息 + 分栏预览
3. **操作显性化**：关键操作（保存、发布）始终可见，次要操作渐进披露
4. **视觉克制**：延续和风樱花粉主题，但后台使用更低饱和度的变体

## 模块详细设计

### 1. 文章管理（核心模块）

**左侧列表区**（280px 固定）：
- 顶部：搜索框 + "新建" 按钮
- 列表项：紧凑行，显示标题 + 日期 + 状态圆点
- 选中项：左侧 3px 樱花色条 + 浅粉背景
- 底部：分页控件

**右侧编辑区**（自适应）：
- 大标题输入框（24px，无边框，placeholder "输入文章标题..."）
- 可折叠元信息面板（slug、日期、标签、封面、状态）
- Markdown 编辑器 + 实时预览（左右分栏，可拖拽调整宽度）
- 底部固定操作栏：保存草稿 | 发布 | 下线 | 删除

### 2. 精选管理

- 网格卡片布局，每卡片显示文章标题 + 封面缩略图 + 精选开关 + 排序输入
- 拖拽排序（未来可扩展）

### 3. 友链管理

- 左侧列表（名称 + URL + 状态）
- 右侧表单（含代码块导入功能保留）

### 4. 关于页 / 名片卡

- 单栏大表单，最大化编辑空间
- Markdown 编辑器全宽

## 样式系统

### 色彩（后台专用变量）
```css
--admin-bg: #fafafa;
--admin-sidebar-bg: #f5f5f5;
--admin-surface: #ffffff;
--admin-border: #e8e8e8;
--admin-text: #1a1a1a;
--admin-text-subtle: #6b6b6b;
--admin-accent: var(--rose-500); /* 樱花粉 */
--admin-accent-soft: color-mix(in oklch, var(--rose-500) 10%, transparent);
```

### 间距
- 边栏内边距：12px
- 内容区内边距：24px
- 卡片/面板间距：16px
- 列表项间距：0（用边框分隔）

### 字体层级
- 页面标题：20px / 600
- 面板标题：16px / 600
- 正文：14px / 400
- 辅助文字：13px / 400
- 标签：12px / 500

## 动效规范

- 面板切换：`opacity 0→1` + `translateY(4px→0)`，200ms ease-out
- 列表项进入：stagger 30ms，从 `opacity 0` + `translateX(-8px)` 进入
- 按钮交互：`transform scale(0.98)` + 颜色过渡，150ms
- 侧边栏导航切换：左侧色条 `width 0→3px` + 背景色过渡
